# adamcaino.github.io
Portfolio and service offering for Microsoft Copilot and Azure AI: a four-step service ladder from readiness assessment to governed AI service, plus anonymised case studies from agent builds, document extraction and adoption work. Static site served via GitHub Pages.

- `index.html`: home page (hero, timings, services, case studies, approach, contact).
- `case-studies/`: one page per detailed case study.
- `styles.css`: shared styles for every page. Colours, fonts and spacing are tokens on `:root`; the layout is fluid and stacks at phone width.
